# نتيجة مراجعة وتنظيف الكود

14 نوفمبر 2026. نقطة البداية `2856604`؛ العمل على `implementation/week1-foundation`.
التنفيذ يحافظ على React/TypeScript/Vite/Supabase والتصميم الحالي، ويطبق الفصل التدريجي
المتفق عليه بدل إدخال frameworks وخدمات جديدة قبل الحاجة.

## نطاق الفحص

فحص TypeScript وLint يشملان ملفات المصدر كلها، بما فيها مكونات UI غير المستعملة حاليًا.
استُخدمت خريطة imports بدءًا من `src/main.tsx` لتحديد الملفات غير المرتبطة بالتطبيق.
المراجعة التفصيلية ركزت على الحسابات والصلاحيات والـrouting، وطلب القصة وحفظها ومعاينتها،
وفحوص الطلبات والمزود والبرومبتات، مع إعادة اختبارات أمان قاعدة البيانات القائمة.
هذا لا يثبت سلامة كل حالة في الخدمة المستضافة أو جودة مخرجات AI الحقيقية.

صافي سطور `src` و`supabase/functions` (TypeScript/TSX/CSS، دون tests أو lockfiles):
**12,537 → 11,961، أي 576 سطرًا أقل.** الرقم يشمل الوحدات الجديدة؛ الهدف إزالة التكرار
ووضوح المسؤوليات، وليس ضغط الكود أو حذف الوظائف لخفض العدد.

مكونات shadcn غير المرتبطة بشاشة حاليًا تُركت كمكتبة UI جاهزة، وهي تُفحص بالأنواع وLint.
عدم وجود import من الصفحة الرئيسية وحده لا يجعل حذف كل المكتبة ومكتباتها قرارًا صحيحًا.

## الاختبارات المنفذة

- `npm run check`: ناجح، بما فيه **صفر أخطاء وصفر تحذيرات Lint**، وفحوص الأنواع وbuild.
  تحذير build لحجم الحزمة الرئيسية ما زال ظاهرًا؛ لم نخفه برفع الحد.
- `npm test`: **58 اختبارًا ناجحًا، صفر فشل وصفر skipped**: 10 للطلبات/الصور،
  22 للمعمارية والأعطال، و26 تكامل PostgreSQL معزول.
- Deno 2.9.6 check بملف lock مجمّد: ناجح للوظيفتين بعد الفصل.
- **12 فحص HTTP محليًا** لمدخلي Edge الحقيقيين: preflight، الطريقة، نوع المحتوى، JSON
  التالف، الحجم الزائد، ورفض الطلب غير المصادق. لا استدعاءات مزود مدفوعة.
- Chromium: الصفحة الرئيسية والخط المحلي، تبديل العربية/الإنجليزية، wizard، إعادة توجيه
  سبعة مسارات إدارة وprofile إلى تسجيل الدخول بلا بدء استعلامات بيانات، lazy 404، وعرض
  الموبايل. اختبار AbortSignal بوسيلة نقل وهمية نجح دون الاعتماد على مزود فعلي.
- فحص المتصفح الأول سبق حركة الانتقال بسبب انتظار ثابت قصير؛ أعيد بفحص ظهور العنصر.
  نموذج النقل الأول لم يعترض SDK getter كما كان مقصودًا؛ صُحح نموذج الاختبار ونجح اختبار الإلغاء.
- `npm audit`: **11 moderate، صفر high/critical**. لم نتجاهل التنبيهات أو ندّع إغلاقها.
  تفاصيل تنبيهي React Router في تقرير التأسيس؛ الترقية الرئيسية لها اختبار منفصل مطلوب.
- `git diff --check`: ناجح. CI أُضيف له أمر الاختبارات الجديدة عبر `npm test`؛ نجاحه
  على GitHub يُثبت بنتيجة تشغيله هناك، وليس بنتيجة الفحص المحلي.

## ما لا يزال مطلوبًا في خطة الـMVP

1. تحقق مستقل من الحساب الإداري التاريخي والجلسات، ومراجعة/تطبيق التغييرات في staging.
2. نقل الحفظ إلى transaction على الخادم مع idempotency؛ التحسين الحالي يكشف الفشل
   ويمنع نجاحًا وهميًا، لكنه قد يترك مسودة أو صفوفًا جزئية إذا انقطع المتصفح.
3. الرفع الخاص للصور وفحص الخادم وإزالة EXIF والموافقة والاحتفاظ والحذف. فحص المتصفح
   لا يحل محل ذلك؛ تخزين المراجع الحالي ما زال يحتاج التطوير المتفق عليه.
4. jobs دائمة واستكمال وتعامل مع إلغاء الخادم، وسقف صرف بالدولار. الحصص الحالية ليست
   ميزانية مالية ولا ضمانًا لإلغاء طلب مزود بدأ بالفعل.
5. Character Bible/Blueprint وصور متسقة وPDF ودفع وتسليم وتجارب الجودة المخططة.
   لم تتحول الأزرار المؤجلة إلى ميزات عاملة بمجرد التنظيف.

لم يُنفذ نشر أو migration على خدمة مستضافة أو تعديل بيانات عملاء أو استخدام API مدفوع.
