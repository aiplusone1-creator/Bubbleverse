# Production quality and experiment discipline

Read repository-root `AGENTS.md`, `CODEX_DIRECTIVES.md`, and `DESIGN.md` when relevant.
Use the current HEAD and task file allowlist; preserve user changes. These are project-authored
instructions adapted from the supplied reference collection, not the missing upstream resources.
No fixed greeting, automatic worktree/subagent, hidden paid call, or extra approval loop.

1. Read the MVP experiment plan. Separate Story Blueprint, Character Bible, narrative, image prompt, optional narration/animation and asset versions.
2. Record provider/model/prompt/reference versions, inputs, attempts, status, quality rubric, latency and estimated/actual cost.
3. Start with synthetic references and stubbed failures. Do not call paid models or send child media merely because the task says test.
4. For an explicitly authorized live experiment, inspect existing bindings without values and enforce the agreed per-run budget and retry bound.
5. Human review covers likeness, identity separation, continuity, language/age suitability, image defects and book readability. Structural validators are not a likeness guarantee.
6. Do not claim video/PDF/print/payment completion from prompts or a text response. Publish examples only with appropriate rights and separate marketing consent.
