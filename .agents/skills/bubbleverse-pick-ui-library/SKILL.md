# Installed and sufficient beats fashionable

Read repository-root `AGENTS.md`, `CODEX_DIRECTIVES.md`, and `DESIGN.md` when relevant.
Use the current HEAD and task file allowlist; preserve user changes. These are project-authored
instructions adapted from the supplied reference collection, not the missing upstream resources.
No fixed greeting, automatic worktree/subagent, hidden paid call, or extra approval loop.

1. Inspect package.json/lockfile and the relevant existing component first.
2. Current defaults are Radix/shadcn, Framer Motion, Vaul, Sonner, React Query, clsx/cva and Recharts where already used.
3. Do not replace Radix with Base UI or introduce Zustand/NumberFlow/another motion library merely because it is in a source guide.
4. Prefer CSS or an existing wrapper for a small change. Introduce a dependency only for a concrete capability gap and explain bundle/maintenance consequences.
5. Do not animate payment totals or invent sales statistics as a library demo. No paid service or unapproved experimental provider is installed by this skill.
