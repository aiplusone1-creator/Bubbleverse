# A broad craft reference, not a redesign mandate

Read repository-root `AGENTS.md`, `CODEX_DIRECTIVES.md`, and `DESIGN.md` when relevant.
Use the current HEAD and task file allowlist; preserve user changes. These are project-authored
instructions adapted from the supplied reference collection, not the missing upstream resources.
No fixed greeting, automatic worktree/subagent, hidden paid call, or extra approval loop.

1. Read DESIGN.md. Optimize the parent journey: understand the offer, configure, upload, preview, pay and retrieve the story.
2. Preserve the current visual personality. Quiet reading/forms/admin deserve different motion budgets from a marketing hero.
3. Inspect active/hover/focus, accessible names, inline validation, empty/pending/error states and target sizes.
4. Reuse installed primitives and variants. Do not add generic design-system layers or dependencies for a small fix.
5. Treat timing/scale/blur guidance as context-sensitive. A fade-only transition is valid; taste alone is not a security or release blocker.
6. Report a concise before/after/why table for review work; implement and test when the request authorizes fixes.
