# Manual, bounded design exploration

Read repository-root `AGENTS.md`, `CODEX_DIRECTIVES.md`, and `DESIGN.md` when relevant.
Use the current HEAD and task file allowlist; preserve user changes. These are project-authored
instructions adapted from the supplied reference collection, not the missing upstream resources.
No fixed greeting, automatic worktree/subagent, hidden paid call, or extra approval loop.

1. Read docs/skills/PROTOTYPES.md. Scope one component and normally two or three genuinely different directions.
2. Use existing tokens, surrounding context, Arabic/English fixtures and working local interactions.
3. Use explicit mock transport and synthetic media. No actual signups, generation credits, payment sessions or public child images.
4. Keep a prototype dev-only with no production imports from it; the picker is neutral and does not change the product theme.
5. Verify each variant, report tradeoffs and let the owner choose the visual direction. Integrate only the chosen/authorized version and remove or explicitly retain the harness.
