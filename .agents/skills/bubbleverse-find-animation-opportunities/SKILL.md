# Filter opportunities, do not add a motion wishlist

Read repository-root `AGENTS.md`, `CODEX_DIRECTIVES.md`, and `DESIGN.md` when relevant.
Use the current HEAD and task file allowlist; preserve user changes. These are project-authored
instructions adapted from the supplied reference collection, not the missing upstream resources.
No fixed greeting, automatic worktree/subagent, hidden paid call, or extra approval loop.

1. Default to read-only suggestions. Inspect existing tokens, frequency and purpose before recommending additions.
2. Bubbleverse already contains ambient motion. Reject additions that compete with child photos, story reading, consent or purchase decisions.
3. Cap a whole-app report at five high-value suggestions, each with path, purpose, cost and Reduced Motion behavior.
4. Name candidates deliberately rejected. Do not infer weak-device FPS from the cloud browser.
5. If the user also authorized implementation, hand the selected scope to bubbleverse-animate in the same task; do not manufacture an extra approval checkpoint.
