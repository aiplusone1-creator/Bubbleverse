# Select principles, not an Apple redesign

Read repository-root `AGENTS.md`, `CODEX_DIRECTIVES.md`, and `DESIGN.md` when relevant.
Use the current HEAD and task file allowlist; preserve user changes. These are project-authored
instructions adapted from the supplied reference collection, not the missing upstream resources.
No fixed greeting, automatic worktree/subagent, hidden paid call, or extra approval loop.

1. Keep Bub, existing palette and rounded/glass identity. Apply immediate feedback, spatial consistency and legible hierarchy where useful.
2. Do not replace Fredoka or add system-font defaults without a typography task. Do not apply Latin tracking rules to connected Arabic.
3. Prefer static glass with opacity/transform transitions. Animated blur requires a measured reason and a low-cost fallback.
4. Use the installed Framer Motion APIs; Apple damping ratio is not a Framer damping coefficient. Do not copy numeric spring parameters between models.
5. Transaction pending/duplicate-submit controls remain valid; interruptible cosmetic motion does not authorize repeated generation or payment.
6. Verify keyboard, RTL and reduced-motion behavior. Never add sound/haptics as the only feedback or enable them by default.
